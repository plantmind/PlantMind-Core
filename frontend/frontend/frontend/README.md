# Frontend

## Purpose

The Frontend is the user interface of PlantMind.

It provides engineers, operators, supervisors, and management with a secure and intuitive interface to interact with PlantMind.

## Features

- Dashboard
- AI Chat Assistant
- Equipment Explorer
- Knowledge Graph Viewer
- Alarm & Event Viewer
- Trend Analysis
- Incident Workspace
- Shift Handover
- Reports

## Planned Technologies

- React
- TypeScript
- Tailwind CSS
- REST API
- WebSocket
