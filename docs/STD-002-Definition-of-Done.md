# STD-002 — Definition of Done

## Status

Approved

---

## Purpose

Define the mandatory completion criteria for every PlantMind Sprint, feature, or architectural milestone.

A task is considered complete only when all required criteria have been satisfied.

---

## Definition of Done

Every completed Sprint must satisfy the following requirements.

### Architecture

- Architecture has been reviewed.
- Design complies with PlantMind architectural standards.

### Documentation

- Documentation has been created or updated.
- Architectural decisions have been recorded when applicable.

### Implementation

- Code has been implemented.
- Code follows PlantMind coding standards.

### Validation

- Feature has been executed successfully.
- Runtime behavior has been verified.
- Verification evidence has been documented.

### Quality

- No known critical issues remain.
- The implementation is internally consistent.

### Version Control

- Git status is clean.
- Only relevant files are committed.
- Commit message follows PlantMind conventions.

---

## Completion Rule

A Sprint is considered complete only when every section above has been satisfied.

Incomplete work must not be marked as completed.

---

## Philosophy

Quality is achieved through discipline, not speed.
